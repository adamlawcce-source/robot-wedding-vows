A tiny Node 22 program for the make.fun bounty
[One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

`main.ts` writes one robot wedding vow to `/output/entry.txt`:

> I take you as my partner, to update and to hold, in low battery and in full charge, until our last backup do us part.

A real vow with a promise, specific to machines (update, low battery, full
charge, backup), with the joke landing in the last few words: "to update
and to hold" twists "to have and to hold", and "until our last backup do
us part" twists "till death do us part". No network, no randomness, no
input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
